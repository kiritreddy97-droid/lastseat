# LastSeat India: Financial Model

Illustrative unit economics. Replace every assumption with measured data as you learn.

| Assumption | Value |
|---|---|
| Price per pass holder (INR) | 25,000 |
| Volume Y1 / Y2 / Y3 (pass holders) | 1,000 / 5,000 / 20,000 |
| Variable cost per unit (INR) | 1,200 |
| Revenue shared out (airline/partner) | 35% |
| Acquisition cost per unit (INR) | 3,000 |
| Fixed costs Y1 / Y2 / Y3 (INR) | 8,000,000 / 20,000,000 / 45,000,000 |

Run `python finance/model.py` for the projected profit table. Edit `PARAMS` in that file to test scenarios.
