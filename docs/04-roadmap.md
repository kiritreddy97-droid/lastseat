# LastSeat India: Roadmap

## Phase 0 - Airline pilot (weeks 1-8)
- Pitch deck + data model to 3 airlines
- Landing page waitlist
- Define fences: window, routes, caps

## Phase 1 - Pilot (months 3-5)
- Seat publish API and booking flow (this repo's backend)
- Manual ticketing with the airline's group desk
- 500-member cohort

## Phase 2 - Integrate (months 6-9)
- PSS/airline API integration
- Mobile app, push alerts for new seats
- Automated refunds and priority rebooking (built against fake payment/notification providers; real providers pending)

## Phase 3 - Scale (months 10-12)
- More airlines and routes
- Dynamic caps by route demand
- Bundles with hotels

Timings are planning estimates for a small team; re-plan at the end of each phase.
